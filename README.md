# ЦОД Экибастуз — web AR

**Open: https://laniakea00.github.io/dcv-ar/**

A static page: the phone camera finds the printed mat under the 3D-printed maket (`print/board_A4.pdf`, print at
100 %) and draws the DCV data center model on it. Without the mat it is a plain 3D viewer.

This repo is only the published copy. The source (tracker, tests, tools) lives in the private `qtwin-io/cod-ar-viewer`,
branch `web-AR`, folder `web/`. three.js r179 (MIT) in `vendor/three/`.
